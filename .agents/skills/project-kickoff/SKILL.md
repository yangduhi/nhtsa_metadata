# Project Kickoff

Use this compatibility skill when starting a new phase in `nhtsa_metadata`.

1. Prefer repo-local skills under `.skills/` for detailed procedures.
2. Read the active phase work order and relevant contract docs.
3. State assumptions, impact scope, and success criteria.
4. Implement only the approved phase.
5. Keep default verification fixture/mock only; live work must be manual and bounded.
6. Write or update the phase report before claiming completion.
